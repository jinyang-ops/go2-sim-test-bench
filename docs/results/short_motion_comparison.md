# 短程前进测试：50 轮启动模型与 1000 轮平地模型

日期：2026-11-02。

## 来源与结论范围

本记录整理使用者在其 Ubuntu 22.04 / RTX 4060 Laptop 电脑上运行评估后提供的 summary.json。两个模型各一个回合，均不是助手云端仿真结果。

1000 轮平地模型在这个回合达到了 1m 前进目标；50 轮启动模型未达到。这个结论不代表多回合稳定性、复杂地形通过能力或实机能力已经得到验证。

## 共同评估条件

- task=go2，headless，num_envs=1，seed=0。
- terrain=competition，case=nominal。
- 固定起点附近的短程测试：出生原点 x=2、y=6。
- 速度指令 1.0m/s；目标前进距离 1m；最大仿真时间 5s。
- 评估在达标、失败或到达时限时结束，并保留重置前物理状态。

## 比较边界

- 新模型提前达到目标而结束，旧模型运行到时限；两者速度误差和力矩的统计时长不同。不能把数值变化直接宣称为固定时长下的误差下降比例或能效提升。
- 两次训练的轮数、并行数量与训练地形均有变化，不构成只改变一个因素的消融实验。
- 平均绝对力矩不是能耗，较大的值也不能单独说明控制质量更好或更差。
- 一次达标不能证明“成功率 100%”的总体性能；这里只能表述为 1/1 回合达标。
